# 钢铁雄心 · 浏览器版

一款在浏览器里运行的**实时制二战策略游戏**（玩法灵感来自《钢铁雄心 / Hearts of Iron》）。你扮演一个国家，在真实世界地图上调兵遣将、宣战求和、发展工业与科技，见证世界局势在时间流速中动态演变。

纯前端实现：**无框架、无构建步骤**，打开浏览器即可游玩。

---

## ✨ 主要特性

- **真实世界地图**
  - 基于 `d3-geo` + `topojson-client` + `world-atlas` 渲染
  - 开局为**欧洲战场**，真实国界作为稳定底图，控制权按省份实时染色
- **实时战略指挥**
  - 出兵路线选择器、部队移动与战斗动画
  - 不宣而战、宣战、求和、空袭等军事/外交手段
  - 开局保护期、AI 宣战机制、AI 求和系统
- **国家经营与内政**
  - 资源体系：政治权力、稳定度、战争支援度、民用工厂、军用工厂、装备、人力、钢铁、石油、稀有材料
  - 国策、科研、外交、投降等国家行为
- **地图模式切换**：政治 / 地形 / 外交
- **时间变速系统**：暂停、慢速、常速、快速（游戏内日期从 1936 年 01 月推进）
- **日志分类**：全部 / 战报 / 外交 / 事件 / 生产

---

## 🧱 技术栈

| 层    | 技术                                        | 说明                                    |
| ----- | ------------------------------------------- | --------------------------------------- |
| 前端  | HTML / CSS / JavaScript（原生）             | 无框架、无构建、无打包                   |
| 地图  | d3-geo 、topojson-client 、world-atlas      | 仅用于地图数据的准备与渲染（npm 依赖）    |
| 服务器| Python 标准库 `http.server`（`server.py`）  | 本地开发 / 云端部署共用一个静态服务器     |

> 游戏运行本身**不依赖 npm**；`package.json` 中的依赖主要用于地图数据生成/加工。

```

```

## 🚀 本地运行

需要：Python 3（建议 3.8+）。

```bash
# 在项目根目录执行
python server.py
```

默认监听 `http://127.0.0.1:8642`，浏览器打开即可游玩。

如需自定义地址/端口：

```bash
# Windows PowerShell
$env:HOST="0.0.0.0"; $env:PORT="8080"; python server.py

# Linux / macOS
HOST=0.0.0.0 PORT=8080 python server.py
```

> 也可以用任意静态文件服务器（如 `npx serve`、VS Code Live Server）直接托管项目根目录。

## ☁️ 部署到 GitCode DevStation

项目已适配华为云 DevStation 的 Web 环境：

- `.devenv/init.sh` 会在云端启动时执行，设置 `HOST=0.0.0.0`、`PORT=8080`，并后台运行 `server.py`；
- 端口 `8080` 位于 DevStation 允许放行的 `8080–8089` 范围内；
- 访问日志写入 `/tmp/steelambition-web.log`。

DevStation 会自动执行 `.devenv/init.sh`；若需手动启动，可在终端执行：

```bash
bash .devenv/init.sh
```

## 🎮 玩法速览

1. 启动后选择**国家、剧本、难度**，进入 1936 年的欧洲局势。
2. 顶部栏查看与调配：政治权力、稳定度、战争支援度、工厂、装备、人力与战略资源。
3. 左下角使用**变速控制**推进时间；默认日期从 **1936 年 01 月** 开始。
4. 通过 **国策 / 科研 / 外交 / 投降** 按钮制定国家战略。
5. 在地图上选择省份出兵、规划路线；观察前线红条带与战斗动画。
6. 切换**政治 / 地形 / 外交**地图模式，掌握全局。
7. 在底部日志中按 **全部 / 战报 / 外交 / 事件 / 生产** 分类查看动态。
