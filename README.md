# 钢铁雄心 · 浏览器版

一款在浏览器里运行的**二战策略游戏**（玩法灵感来自《钢铁雄心 / Hearts of Iron》）。你扮演一个国家，在全球地图上组织进攻、扩充军队与争取盟友；后勤可以自动安排，也可以手动管理。

纯前端实现：**无框架、无构建步骤**，打开浏览器即可游玩。

---

## ✨ 主要特性

- **真实世界地图**
  - 基于 `d3-geo` + `topojson-client` + `world-atlas` 渲染
  - **全球战区**，历史国界作为稳定底图，控制权按战略省区实时染色
  - 新开局合并城市微省与零碎陆区，柏林、汉堡、华沙等保留首都/港口能力并整合相邻腹地；省界共用平滑曲线，填色、点击和邻接同步。相邻国家与反对派采用差异化配色，详见[v52说明](docs/2026-10-17-map-war-v52.md)
- **自动推进的战争指挥**
  - 默认4秒推进1天，可切换6秒或2秒；随时暂停布置，没有回合或行动次数限制。点城市下达出征、调兵与训练命令，右侧指挥卡按需打开
  - 各国按日同步行动；普通新闻在角落短暂汇总，敌袭持续提醒并暂停；前线边界随突破推进，政治底色只在真正占领后改变
  - 按日持续作战：准备、接敌、突破，途中可改战术、增援、请求盟友支援或撤退
  - 出征与增援独立选择步兵、坦克辆数和飞机架数，优先近邻；战场直接显示装甲突破、航空支援效果，谨慎保兵慢推、均衡作战、强攻高风险快推。港口兵牌显示真实舰艇数量
  - 陆军可沿本国与直接盟国的真实接壤行军，远程增援抵达前不投入火力；下达有效战术或确认出征后继续推进
  - 自己不接壤时可从地图或前线卡请求接壤盟军进攻，确认后召集参战并出动盟友自己的军队，不凭空改色；政治地图同一控制国统一底色
  - 坦克对抗装甲、飞机争夺制空，优势进一步影响步兵战损；港口可安排真实舰队海运撤离，运力与燃油有限，在途部队抵达前不能作战，战报区分获救、被俘与阵亡
  - 舰艇采用游戏节奏的按日建造：驱逐舰、潜艇12天，主力舰24天，航母36天；仍支付完整费用并需要本国港口。训练页、全国队列和港口卡显示相同剩余天数
  - 新战役采用百万兵力游戏配置：主要大国实际陆军400万至800万人，1936德国约551万；按原兵种及欠员比例扩军，首页预览显示真实人数，非历史统计
  - 兵员、坦克、飞机在顶栏及军队卡并列显示实际人数、辆数与架数；军备按国家和年代独立配置，不随百万陆军机械倍增。舰艇按艘计算，空中支援和装甲损耗影响真实装备，详见[v51说明](docs/2026-10-16-force-consent-v51.md)
  - 不宣而战、宣战、求和、空袭等军事/外交手段
  - 开局保护期、AI 宣战机制、AI 求和系统
- **国家经营与内政**
  - 默认全省自动征兵：按全国有限训练额度、兵源与装备轮转分配，训练完成后补充驻军；可调整强度和兵种，保留强制征兵。后勤安排研究与装备贸易
  - 训练与研究默认收敛到步兵、坦克、飞机、海军；专业兵种、支援科技和行政管理按需展开，显示真实效果、解锁与进度
  - 结盟、吞并、归附及战时劝降均可免费提案，无政治点、关系、年代与拒绝冷却硬门槛；确认后才收到对方回复，按实力、民意及败势接受、折中或拒绝。扶持傀儡政府改为秘密援助反对派，增加动乱风险，不需现政府同意，也不立即转移领土
  - 同盟与和平合并更易协商，战时劝降只在严重亡国危机下奏效；自动投降要求首都失守及至少85%本土胜利点沦陷，避免普通败仗就让完整国家退出。各国可形成不依赖玩家的多个真实战区
  - 同盟看保护实力与共同威胁，保留对方独立；和平吞并看独立意愿和民意，结盟不会保证吞并。自动及谈判受降移交存活陆海空、在途军队、库存和未完军备，不清空败国军队
  - 稳定不足、持续资源短缺、伤亡、失地和外国干预会积累内乱压力，正常治理可缓解；反对派以有限力量起步并通过真实战斗扩张，不按固定日期爆发。国外内乱记入世界大事，不长期遮挡地图
  - 自动后勤正常消耗资源并保留储备，不会自动宣战或选择进攻目标
  - 装备后勤默认每月补损并安排坦克、飞机及舰艇生产，保留手动训练、开关与强度；主权提案结合双方综合军力、民意、独立意愿、战争损失和第三国保护，相同局势不靠重复点击刷接受
  - 占领区有独立民意与抵抗；安抚和足额驻防可缓解风险。低民意下弱小守备会遭游击损耗，失去守备后可能建立真实抵抗政权，使用有限地方后备且邻省仍须战斗夺取
  - 起义军可从有限地方后备与真实物资补足可战规模，原有军队不复制或治疗；吞并反对派不抹除原民族身份，也不会永久消除原政府的叛乱风险。政治模式统一控制国纯色，选中与突破用边线表达，详见[v53说明](docs/2026-10-17-rebellion-diplomacy-v53.md)
  - 资源体系：政治权力、稳定度、战争支援度、民用工厂、军用工厂、装备、人力、钢铁、石油、稀有材料
  - 国策、科研、外交、投降等国家行为
- **地图模式切换**：政治 / 地形 / 外交
- **全球总览**：战争与同盟关系图、完整关系清单、国家搜索和已掌握的军力
- **可选实操教程**：从真实选部队、选目标与战术到观察行军和跨日，不干预存量战役
- **日志分类**：全部 / 战报 / 外交 / 事件 / 生产

## 🧱 技术栈

| 层    | 技术                                        | 说明                                    |
| ----- | ------------------------------------------- | --------------------------------------- |
| 前端  | HTML / CSS / JavaScript（原生）             | 无框架、无构建、无打包                   |
| 地图  | d3-geo 、topojson-client 、world-atlas      | 仅用于地图数据的准备与渲染（npm 依赖）    |
| 服务器| Python 标准库 `http.server`（`server.py`）  | 本地开发 / 云端部署共用一个静态服务器     |

> 游戏运行本身**不依赖 npm**；`package.json` 中的依赖主要用于地图数据生成/加工。

## 🚀 本地运行

需要：Python 3（建议 3.8+）。

```bash
# 在项目根目录执行
python server.py
```

默认监听 `http://127.0.0.1:8642`，浏览器打开即可游玩。

如需自定义地址/端口：

```bash
# Windows PowerShell
$env:HOST="0.0.0.0"; $env:PORT="8080"; python server.py

# Linux / macOS
HOST=0.0.0.0 PORT=8080 python server.py
```

> 也可以用任意静态文件服务器（如 `npx serve`、VS Code Live Server）直接托管项目根目录。

### 固定正式网址与自动发布

正式游戏：[gangtiexiongxin-game.netlify.app](https://gangtiexiongxin-game.netlify.app/)。

本地仓库启用 `git config core.hooksPath .githooks` 后，每次完整提交自动测试、构建、发布到已关联 Netlify 站点，再检查正式网址的版本与缓存头。首次使用需要原有 Netlify 账户已登录；新克隆也需要重新启用 Hook。失败会显示“发布失败”，可运行 `npm run deploy` 重试，提交成功本身不代表上线成功。

`npm run build` 自动为每个 JS/CSS 生成内容指纹，并生成 `dist/version.json`（版本、build、commit）。只发布 `dist`，不会上传开发文件。所有页面和资源通过 `_headers` 强制重新校验缓存；正常打开原网址会获取最新已发布版本，无需手改网址或资源版本号。开始界面底部显示版本和 build，方便核对。

本地未提交修改不会直接上传。交付必须完成提交后的生产发布和实际网址验收。

项目已适配华为云 DevStation 的 Web 环境：

- `.devenv/init.sh` 会在云端启动时执行，设置 `HOST=0.0.0.0`、`PORT=8080`，并后台运行 `server.py`；
- 端口 `8080` 位于 DevStation 允许放行的 `8080–8089` 范围内；
- 访问日志写入 `/tmp/steelambition-web.log`。

DevStation 会自动执行 `.devenv/init.sh`；若需手动启动，可在终端执行：

```bash
bash .devenv/init.sh
```

## 🎮 玩法速览

1. 选择**国家、剧本、难度**，自行选直接指挥或新手教程。新战役默认使用增强兵力，进入后自动推进；教程先暂停引导，右侧指挥卡按需打开。
2. **点敌城**，系统推荐可达的出发地；也可从我方城市选择出征。选择战术后确认进攻，部队按实际路线行军并自动交战。陆军能经过本国与直接盟国的连续接壤城市，不能经过中立国或敌国的中间城市；隔海需要港口、航线和舰队，空军调动受航程限制。
3. **征兵默认自动**，每月按可用人力和装备安排训练，并保留储备。预备兵源每天恢复；城市 → 征兵或更多 → 军队与训练可手动训练、调整自动强度和兵种，也能用**紧急动员**补充兵源、**征收赋税**补充钢铁与装备，两项行动有代价和30天冷却。新兵优先前线和可用港口。**城市更多**中可建设要塞和补给，队列中的项目不能重复下单。调兵、驻军明细和海空军高级行动位于展开项。
4. **随时暂停布置**：顶栏或战场卡可暂停/继续，默认**4秒/天**，节奏菜单可选6秒/天或2秒/天。没有全国行动次数限制，命令仍受兵力、路线和资源条件约束。出征按行军、接敌、突破推进，完成后才占领。调整兵力时暂缓时间，滑条连续拖动，实际派出数量按整支部队计算；取消布置后恢复此前的推进状态。连续攻势默认关闭，可自行开启。
5. **各国同步行动**：每天AI主动决策和战斗，月末结算经济、研究和训练。必选事件和敌袭会暂停；最后一条警报确认后恢复此前推进档位，查看战场则继续暂停便于布置。正在调整命令或查看全球总览时，不会因确认警报而抢先恢复。普通新闻3.5秒后清除，更多 → 世界大事和战况记录保留历史。
6. **外交**选择国家后结盟、宣战或议和。新战役默认自动后勤，可在更多 → 后勤与发展关闭或手动安排；国策、科研与任务保留在更多菜单。
7. **Space暂停/继续**，Esc取消命令或关闭面板；输入、按钮与全球总览聚焦时不触发背景快捷键。平板单指点选/拖图、双指缩放，侧栏和菜单可以滚动。**全球总览**同时查看冲突与同盟，选择国家可定位地图或打开外交；关闭后按此前状态恢复。
8. **更多 → 保存战役**保存，每天推进和成功命令也会自动保存。继续战役恢复部队、控制权、在途行军、必选事件与警报；旧回合档取消行动预算和待结算余日，不补跑日期。旧档保留原地图与军队，不自动扩军或拆分。存档属于当前浏览器及当前地址，换端口不会自动同步。

本次参考来源、设计取舍与实现范围见[地图城市玩法设计](docs/2026-10-09-map-first-design.md)。

## 历史开局与兵种

地图使用 CShapes 1936 全球快照与欧洲细节，物理背景使用 Natural Earth 10m 岸线。新开局欧洲邻接的小行政区合为作战区，保留主要城市、首都、港口与独立岛屿；其他地区增加城市战略分区。v49在456区基础上再合并29区，只合并同一旧战略来源内真正接壤的陆区，不隔海拼接。来源与近似见[全球地图说明](docs/world-map-sources.md)和[v49说明](docs/2026-10-15-map-military-v49.md)。1939/1941 的占领与轴心盟友分别配置；未声称精确还原逐日占领线。旧档保留控制区和原部队、库存与研究。

地图远景隐藏次要城市并汇总部队，放大后逐步显示城市和驻军人数；兵种明细在城市卡中查看，选中目标优先显示。地图导航可直接切换欧洲、亚洲、美洲、非洲、太平洋，或回到本国。

23类兵种按陆海空分类，新增轻装甲、重装甲、工兵、坦克歼击和守备部队；部分装备需对应科技与年代。只有陆军可以占领陆地。历史开局后自由推演，日期事件提供史实参考，不会强制复制真实战果。

历史参考配置按师级规模估算，例如1939德国约103师，当前可战陆军约94.9万人；1941德国约208师/苏联约303师。**v49新战役采用百万兵力游戏配置**：德国1936至少550万实际兵员、1939至少600万、1941/42至少700万；苏联800万，中国600万，英美日意及战前法国400万，自由法国保留少量幸存编制。按原兵种及欠员比例扩军，其余国家约2倍，战斗群拆分本身保持人数守恒。增强配置不属于历史人数断言，首页直接展示实际人数，详见[v49说明](docs/2026-10-15-map-military-v49.md)。

兵力人数由实际单位的编制与剩余实力派生，休整只恢复组织度，补员需要真实人力与装备；拆分战斗群本身不增加人数。战斗中的“估算减员”是失去战斗能力的人力折算，不代表真实历史阵亡统计。师数、兵种和驻地均标为近似；官方史料支持的锚点与游戏估算明确分开，详见[编制来源](docs/2026-10-01-army-sources.md)。参考原作组织度、战斗计划、补给与增援原则的[日制战争设计](docs/2026-10-01-daily-war-design.md)说明保留的核心功能及简化方式。

本次交互参考 4399 于 2015-12-16 发布的[《三国时代》](https://www.4399.com/flash/167316.htm)官方操作说明，采用以选城、出征、征兵和占领为中心的流程；具体推演与战斗规则仍由本项目的二战模型决定。
