# 钢铁雄心 · 浏览器版

一款在浏览器里运行的**二战策略游戏**（玩法灵感来自《钢铁雄心 / Hearts of Iron》）。你扮演一个国家，在全球地图上组织进攻、扩充军队与争取盟友；后勤可以自动安排，也可以手动管理。

纯前端实现：**无框架、无构建步骤**，打开浏览器即可游玩。

---

## ✨ 主要特性

- **真实世界地图**
  - 基于 `d3-geo` + `topojson-client` + `world-atlas` 渲染
  - **全球战区**，历史国界作为稳定底图，控制权按战略省区实时染色
- **实时战略指挥**
  - 可暂停实时地图：点城市下达出征、征兵、建设命令；右侧指挥卡按需打开
  - 各国在同一天行动，重点战争事件在地图中央播报；城市边界平滑，攻城颜色随突破进度推进
  - 按日持续作战：准备、接敌、突破，途中可改战术、增援、请求盟友支援或撤退
  - 按历史师级编制配置万人级军队，人数由编制和当前实力估算；有限正面与预备队，组织度和实力分开消耗
  - 不宣而战、宣战、求和、空袭等军事/外交手段
  - 开局保护期、AI 宣战机制、AI 求和系统
- **国家经营与内政**
  - 新战役默认开启自动后勤，按库存与队列安排军事研究、装备贸易及基础增援；可随时关闭
  - 自动后勤正常消耗资源并保留储备，不会自动宣战或选择进攻目标
  - 资源体系：政治权力、稳定度、战争支援度、民用工厂、军用工厂、装备、人力、钢铁、石油、稀有材料
  - 国策、科研、外交、投降等国家行为
- **地图模式切换**：政治 / 地形 / 外交
- **时间变速系统**：暂停、慢速、常速、快速（游戏内日期从 1936 年 01 月推进）
- **日志分类**：全部 / 战报 / 外交 / 事件 / 生产

## 🧱 技术栈

| 层    | 技术                                        | 说明                                    |
| ----- | ------------------------------------------- | --------------------------------------- |
| 前端  | HTML / CSS / JavaScript（原生）             | 无框架、无构建、无打包                   |
| 地图  | d3-geo 、topojson-client 、world-atlas      | 仅用于地图数据的准备与渲染（npm 依赖）    |
| 服务器| Python 标准库 `http.server`（`server.py`）  | 本地开发 / 云端部署共用一个静态服务器     |

> 游戏运行本身**不依赖 npm**；`package.json` 中的依赖主要用于地图数据生成/加工。

## 🚀 本地运行

需要：Python 3（建议 3.8+）。

```bash
# 在项目根目录执行
python server.py
```

默认监听 `http://127.0.0.1:8642`，浏览器打开即可游玩。

如需自定义地址/端口：

```bash
# Windows PowerShell
$env:HOST="0.0.0.0"; $env:PORT="8080"; python server.py

# Linux / macOS
HOST=0.0.0.0 PORT=8080 python server.py
```

> 也可以用任意静态文件服务器（如 `npx serve`、VS Code Live Server）直接托管项目根目录。

## ☁️ 部署到 GitCode DevStation

### 固定正式网址与自动发布

正式游戏：[gangtiexiongxin-game.netlify.app](https://gangtiexiongxin-game.netlify.app/)。

本地仓库启用 `git config core.hooksPath .githooks` 后，每次完整提交自动测试、构建、发布到已关联 Netlify 站点，再检查正式网址的版本与缓存头。首次使用需要原有 Netlify 账户已登录；新克隆也需要重新启用 Hook。失败会显示“发布失败”，可运行 `npm run deploy` 重试，提交成功本身不代表上线成功。

`npm run build` 自动为每个 JS/CSS 生成内容指纹，并生成 `dist/version.json`（版本、build、commit）。只发布 `dist`，不会上传开发文件。所有页面和资源通过 `_headers` 强制重新校验缓存；正常打开原网址会获取最新已发布版本，无需手改网址或资源版本号。开始界面底部显示版本和 build，方便核对。

本地未提交修改不会直接上传。交付必须完成提交后的生产发布和实际网址验收。

项目已适配华为云 DevStation 的 Web 环境：

- `.devenv/init.sh` 会在云端启动时执行，设置 `HOST=0.0.0.0`、`PORT=8080`，并后台运行 `server.py`；
- 端口 `8080` 位于 DevStation 允许放行的 `8080–8089` 范围内；
- 访问日志写入 `/tmp/steelambition-web.log`。

DevStation 会自动执行 `.devenv/init.sh`；若需手动启动，可在终端执行：

```bash
bash .devenv/init.sh
```

## 🎮 玩法速览

1. 选择**国家、剧本、难度**进入地图。开局暂停；顶栏保留城市、装备、预备兵员和时间，右侧默认留空。
2. **点我方城市**，直接选择出征、征兵、建设。出征后点相邻目标，确认投入人数与留守；也可直接点敌城，由系统推荐可达的出发地。确认进攻会开始时间，无需逐日点击。
3. **征兵**先显示费用和训练时间，确认后扣费并在该城训练。**城市更多**中可建设要塞和补给，队列中的项目不能重复下单。调兵、驻军明细和海空军高级行动位于展开项；全部 18 类兵种仍可在更多 → 军队与训练选择。
4. **战斗持续推进**：行军接敌后开始突破，地图从进攻方向逐步覆盖敌城区域，突破完成后才正式占领。战局卡显示当前归属、进度和双方兵力；增援、撤退可直接操作，战术与战损按需展开。默认连续攻势只攻击已宣战敌国，使用真实部队、保留留守，最多同时两场；可在战局中关闭。
5. **各国同步行动**：每天进行军事决策和战斗，月末结算经济、研究和训练。AI 使用真实部队和资源。敌军开始攻城会自动暂停并显示持久防御警报，点击查看战场或确认；已宣战后每场新的来袭也会提醒，未确认警报会随存档恢复。宣战、重要城市失陷、投降与停战在中央播报；更多 → 世界大事和战况记录保留历史。
6. **外交**选择国家后结盟、宣战或议和。新战役默认自动后勤，可在更多 → 后勤与发展关闭或手动安排；国策、科研与任务保留在更多菜单。
7. **空格暂停/继续**；点城和编辑指令时暂停。速度为慢速 2 秒/日、标准 1 秒/日、快速 0.5 秒/日；1/2/3 切换，5 单步一天，Esc 取消命令或收起卡片。平板单指点选或拖动地图，双指缩放；侧栏和菜单可以正常滚动。需要选择的事件暂停，处理后恢复；仍有未确认防御警报时保持暂停。
8. **更多 → 保存战役**保存。推进日期时也会自动保存；继续战役时恢复部队、战斗、训练和世界事件记录，并保持暂停。存档属于当前浏览器及当前地址，换端口不会自动同步；旧档保留原有军队。

本次参考来源、设计取舍与实现范围见[地图城市玩法设计](docs/2026-10-09-map-first-design.md)。

## 历史开局与兵种

地图使用 CShapes 1936 全球快照与欧洲细节，物理背景使用 Natural Earth 10m 岸线。美国、日本、中国、美洲、亚洲、非洲及大洋洲国家和殖民地均可参与战役，来源与历史近似见[全球地图说明](docs/world-map-sources.md)。1939/1941 的占领与轴心盟友分别配置；同国战略省区仍采用抽象分区，不等同于历史行政省界。完整新国家配置需新开战役，旧存档保留原战役。

地图远景隐藏次要城市并汇总部队，放大后逐步显示城市和驻军人数；兵种明细在城市卡中查看，选中目标优先显示。地图导航可直接切换欧洲、亚洲、美洲、非洲、太平洋，或回到本国。

18 类兵种按陆海空分类，具有地形、混编、反坦克、防空、制空、近距支援、轰炸及海战职责；部分装备需对应科技与年代。只有陆军可以占领陆地。历史开局后自由推演，日期事件提供史实参考，不会强制复制真实战果。

新战役按师级规模扩军，例如1939德国约103师，当前可战陆军约94.9万人；1941德国约208师/苏联约303师。兵力人数由实际单位的编制与剩余实力派生，休整只恢复组织度，补员需要真实人力与装备。战斗中的“估算减员”是失去战斗能力的人力折算，不代表真实历史阵亡统计。师数、兵种和驻地均标为近似；官方史料支持的锚点与游戏估算明确分开，详见[编制来源](docs/2026-10-01-army-sources.md)。参考原作组织度、战斗计划、补给与增援原则的[日制战争设计](docs/2026-10-01-daily-war-design.md)说明保留的核心功能及简化方式。

本次交互参考 4399 于 2015-12-16 发布的[《三国时代》](https://www.4399.com/flash/167316.htm)官方操作说明，采用以选城、出征、征兵和占领为中心的流程；具体推演与战斗规则仍由本项目的二战模型决定。
