# v57 游戏演示

成片：[30 秒 MP4](https://github.com/lihao123456521/frontline-atlas/releases/download/v57-demo/frontline-atlas-demo-v57.mp4)；[发布页](https://github.com/lihao123456521/frontline-atlas/releases/tag/v57-demo)。

## 画面与制作

- 使用正式站点实际运行的浏览器画面与连续帧采集，不使用生成视频或重绘 UI 冒充游戏。
- 以真实交战开场，随后展示四个剧本、军备配比、两万兵员调动、同盟关系和敌袭响应。
- 在 ChatCut Desktop 中编排、叠加中文动效文字并原生导出。画面采集为 1024×576，成片为 1920×1080；不是原生 1080p、30fps 的连续录屏。
- 连续帧片段经过加速；静态界面展示与后期字幕之间不构成额外的游戏事件。各剧本镜头来自不同战役，不是一局跨越四个时代。
- 静音版，无旁白或第三方配乐，适合仓库页面预览。
