# v43 战争指挥与平板兼容

目标：敌军来袭能及时响应，当前战争决策优先，PC 和平板操作稳定，完整提交后固定正式网址更新。

1. 防御警报在真实进攻被引擎接受后生成，区别于宣战。立即暂停，优先于世界消息，确认前不消失，可定位实际战斗，保存和恢复未确认警报。同一战斗只提醒一次。
2. 默认地图和右侧当前对象卡。城市主要操作为出征、征兵，建设和详细兵种按需打开。战斗卡给目标、阶段、突破、双方人数、增援和撤退；战术、士气、损耗和历史按需展开，防御优先。
3. 地图采用 Pointer Events：轻微抖动仍点选，累计移动才拖动，双指缩放保持中心，取消/失焦不留下拖动状态。按钮至少44像素触摸目标，按下跨日刷新不会被删除，页面与面板可正常滚动。
4. 构建只收集入口引用的游戏资源，按内容自动生成指纹版本及 `version.json`，正式服务器强制重新校验缓存。Git post-commit 运行回归、构建、Netlify 生产部署，校验正式主页 build 和版本文件 commit；失败则报告并重试，不把上传中当完成。

验证分为真实引擎和输入事件回归、浏览器真实1939战役 PC 操作与平板尺寸布局、正式网址版本和响应头。桌面浏览器的平板尺寸检查不能代替 iPad/Safari 实机证明。
