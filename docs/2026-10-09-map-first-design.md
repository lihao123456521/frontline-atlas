# v42 地图与城市指挥

用户已选定可暂停的实时地图。默认围绕「选城市 → 出征 / 征兵 / 建设 → 看战线推进 → 应对世界事件」游玩，继续使用二战国家与现有真实部队模型。

参考核对：4399 原版《三国时代》（https://www.4399.com/flash/167316.htm）强调鼠标选城、出征、征兵与占领所有城池；开发者在 TapTap（https://www.taptap.cn/app/724510）说明其目标是用鼠标方便操作，通过有限行动寻找人才、补兵和扩张。4399 手机版本（https://a.4399.cn/mobile/123876.html）介绍 AI 突围与反击。城池功能说明（https://www.gamersky.com/handbooksy/201903/1159164_5.shtml）列出出征、征兵、巡逻、运输和侦察。参考的是可核对的介绍与操作说明，未声称运行原 Flash 游戏或复刻内部算法。

## 设计取舍

只折叠菜单无法改变操作成本；彻底改成行动点回合制与用户选定节奏冲突。本次采用地图城市指挥，复用现有战争引擎，减少常驻指标和选择步骤。

- 顶栏仅国家、领地、装备、预备兵员、日期与暂停/速度。政治、工业和其他资源在管理中查看。
- 地图占满主视野。右面板默认关闭，点城才打开简短城市卡。部队明细与高级动作按需查看。
- 己方城市直接出征、征兵、建设；敌方城市可自动推荐实际可到达的出发地，再确认人数和宣战风险。详细军种、后勤和外交仍可访问。
- 每天各国执行军事指令，月末仅结算经济与生产。保留战争、同盟、补给、真实部队与留守限制。
- 平滑内部共享城市边界，仍按国家与海岸裁剪；战斗时按真实突破值从进攻方向逐步覆盖目标区域，完成前不改变法定控制方。
- 中央短卡播报重点事件，一次一条、去重、有关闭和定位操作。常规播报不停表，必须选择的旧事件仍暂停。完整事件保留在战局记录。

1. UI：index.html / ui.js / map-command.css / world-news.js。通过真实鼠标选城、出征、征兵、建设、关闭与暂停，检查默认无右栏、窄屏无溢出。
2. 地图：map.js / map-fronts.css。验证共享边界、进度 0/中段/完成、多个国家与撤退/读档，不修改控制权。
3. 推演：game.js。验证未修改 1939 剧本多国日制行动、单位守恒、月末不重复、存档迁移和事件去重。
4. 运行现有回归与新功能测试、语法和 diff 检查；截图与浏览器错误单独记录。
