# v42 地图城市玩法验收

完成日期：2026-10-10。基于工作区原有未提交版本继续修改，未提交、推送或发布。

## 完成内容

- 顶栏只保留国家、城市、装备、预备兵员、日期与暂停/速度；窄屏进一步隐藏预备兵员。底部导航为城市、战局、外交、更多。
- 右侧卡默认关闭。点己方城直接出征、征兵、建设；点敌城推荐实际可达的出发地，确认后恢复时间。详细驻军、兵种、调动、科研、经济和日志仍可展开使用。
- 地图每城一条驻军总人数，悬停只给城市、国家与人数。城市共享边采用一致的曲线，填色与命中区域一致；国界和海岸仍使用原历史地理裁剪。
- 战斗按真实突破进度，从进攻方向覆盖目标城市区域，未完成前不改变控制方；撤退与读档清理过期覆盖。
- 各国每天执行军事决策。AI 用真实部队补防并谨慎试探近均势战场；训练正常付费与排队，经济仍在月末结算。
- 宣战、重要城市失陷、停战、投降进入结构化事件流。中央一次一条，支持关闭与有地点时定位；历史记录保留最近40条，读档不重播旧事件，需要选择的事件会暂停快报计时。

在 Codex 内置浏览器、独立测试端口8643操作，避免覆盖8642的原有存档。直接鼠标/按钮操作，没有注入战役状态。

1. 1280×800新开1939德国：默认无右卡，地图可视，顶栏与底部操作保持固定。
2. 点击波兹南 → 进攻这座城市 → 确认进攻：推荐捷克斯洛伐克首都，投入12.1万人、留守3.6万人；确认后自动行军。
3. 1939-09-12暂停：波兹南突破54%，实际归属仍是波兰；同时存在莱茵防御和克拉科夫进攻。继续推进后城市数由7增至8，地图显示波兹南“已占领·德国”。
4. 己方城市征兵：装备240→230，训练队列为步兵师→柏林·1月。建设要塞后加入队列，同一按钮禁用。
5. 390×844继续存档：保持暂停，右卡收起。城市列表→柏林→征兵可点击；确认按钮在屏内；document scrollWidth=390。城市标签位于卡片上方，底部战局按钮不换行。
6. 在测试存档中通过外交确认对丹麦宣战：中央显示“德国向丹麦宣战”及当天日期，时钟保持原暂停状态。原战役数据未被此测试改写。
7. 浏览器错误与警告记录为空。资源版本42.1，避免旧CSS/脚本缓存影响验收。
