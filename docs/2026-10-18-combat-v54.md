# v54：推进渐变、攻防平衡与包围坚守

## 目标与边界

- 交战中沿真实进攻方向和推进区域逐渐叠加进攻国颜色，前沿羽化；只有战斗胜利才改变省份控制权。稳定政治地图继续保持同国纯色，不恢复整层模糊、旧属国色或悬停混色。
- 检查地形、要塞、战宽、实际参战规模、火力与组织度，避免防御修正既使守军近乎无伤，又让缺少修正的守军被小分队固定比例消耗。
- 无陆路退路的守军不能因突破进度或组织耗尽直接从全国兵力中消失；仍有可战兵力时继续抵抗、真实减员。海运必须使用有限舰队、容量、燃油与真实航线，未装船者继续坚守。
- 不修改全国投降的完整移交规则，不复制或治疗军队，不把被俘、撤离计为阵亡。不扩大到本轮无关的外交、内乱或造舰平衡。

## 执行与验证

1. 先用失败回归覆盖政治模式推进填色，以及不同地形、双方兵力比、缩编部队与孤立守军。
2. 地图实现独立战场渐变；战斗实现统一预估和实战的连续修正、按实际火力约束损耗，以及包围最后抵抗。
3. 战场卡解释“包围坚守”，不把高突破误报为已占领；保留增援、战术与合法撤离入口。
4. 运行定向与全量 Node 测试、Python 服务测试、差异检查；浏览器检查真实出征、推进前后颜色、战报和横竖屏命令命中。
5. 提交完整源代码，经项目发布流程部署；以固定正式网址的版本、构建指纹、匿名资源和实际交互验收。

## 实现口径

- 每个战场独立渐变与裁剪，推进后方用进攻国色，移动前沿羽化；95%以后羽化范围逐步收窄。没有交战的稳定控制面不混色。
- 地形与要塞只提供有限守备收益，不额外生成反击火力；实际攻击、守备、兵种、装备和补给共同参与计算。双方伤害按当前实力分配，欠员与同人数缩编不会承受不同数量级的减员。
- 没有真实陆路退路的守军将突破封顶95%，低组织仍可抵抗；到初始兵力1%以下且不超过200人的最后残兵才可能被俘。正常有退路的守军仍可撤退，直接盟国邻省可接纳原所属军队。
- 近崩线时使用真实可用舰队分批撤离；未装船守军继续战斗，海运在途不能作为已抵达兵力。主动撤离和自动救援计入战果，不计为阵亡。
- 双方同时组织耗尽时，不能靠结算顺序让进攻方偷胜。全国正式投降仍完整移交存活军队与装备。
- 1941世界行动审计保留14日内实际行军与交火，30日内要求真实非玩家占领，不再用14日速占倒逼战斗过早结束。
