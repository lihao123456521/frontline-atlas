# 战争交互精简

用户授权继续全面优化，沿用历史开局＋自由推演、自动后勤可关闭、战争和同盟优先。

采用目标驱动操作：前线合并重复省份目标，推荐真实可用的出发部队，默认最多四个目标，更多目标折叠；可按敌国切换战场。玩家选目标后必须确认，调整路线、出兵数量、多路协同保留于展开区。确认后回到前线看结果。

地图删除中心到中心的战线及各种长箭头；用屏幕尺寸稳定的出发/目标/候选标记。战果只在玩家涉及的目标附近短暂显示，AI 互战不堆叠动画。保持地图几何、点击、军种规则及全球区域导航。

军队保留兵种与训练队列，删除重复的批量训练按钮，专业兵种折叠；省份建设收起，攻击与调动优先。外交主动作随盟友/敌国/中立关系变化。重复时间按钮收为时间设置；保留暂停/继续与推进月份。

启动时在业务脚本之前捕获首次加载/运行错误，入口检查依赖，提供明确重载入口。验收复现单线程服务被空闲预连接阻塞，服务改用 ThreadingHTTPServer；回归包含空闲连接与并发资源完整性，浏览器重新检验首次进入。

实施与验收：地图覆盖层和 UI 分工执行，根代理负责外壳/样式/启动恢复与集成；回归覆盖目标去重、有效推荐、取消不扣费、不攻击盟友、默认留守、战斗后返回、零长线及标记缩放。真实浏览器检查战争/登陆、同盟、军队、后勤、世界/区域导航，桌面和窄窗口布局。
