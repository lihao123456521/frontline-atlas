# 历史地图与兵种改进

用户选择：历史开局＋自由推演。保留原有界面和沙盒任务，扩充欧洲国家、地理与军事规则。

- 地图：高分辨率海岸线，独立细线国界，去掉模糊和立体高光；使用有日期的历史边界数据。政治控制与几何裁剪分离，避免剧本占领后区域消失。保留原有省份 ID 以兼容存档。
- 开局：纠正合并国家、爱尔兰归属、1939 战争与1941控制权；陆地邻接限制为真实接壤国家和同国区域，海峡走海路。历史开局不强制后续结果。
- 兵种：陆军加入民兵、山地、海军陆战队、摩托化、轻重坦克、反坦克；空军区分战斗机、近支和轰炸；海军区分驱逐舰、潜艇、主力舰。加科技门槛、地形和作战职责，避免飞机舰艇直接占领陆地。
- 验证：真实规则单测、旧存档、三个剧本、地图边界与海洋命中、浏览器生产/科研/地图实测与截图。对历史数据和抽象省份的精度限制据实记录。

分工：地图任务负责 map.js、地图样式和生成数据；军事任务负责 data.js 的 TECHS/UNIT_TYPES/图标区、game.js、ui.js 和军事测试；主任务负责新历史配置、历史数据来源与开局契约、集成及验收。各任务保留他人修改，未授权提交或发布。
