
## 2026-09-30 游戏改版验收
- 根因：变换后的 SVG 置于 overflow:hidden 容器，聚焦会触发内部滚动，使任务栏移出视野；另外浏览器复用旧资源时，本地语法正确仍可能出现 UI 未定义。
- 缺失检查：未在地图聚焦后检查容器 scrollTop 和任务栏屏幕坐标；未核对浏览器实际脚本版本。
- 防错规则：地图不可滚动容器使用 overflow:clip；验收包含实际调兵、地图聚焦后任务栏位置、返回开始页/继续、窄屏边界；脚本更新后提高资源版本，重新加载并核对运行错误。

## 2026-09-30 历史地图与兵种
- 根因：低分辨率边界再次粗化、场景控制者被用作裁剪身份、陆海空共用占领逻辑，使地图和军事失真；场景后成立国家在覆盖领土前计算人力，留下零上限；海军失港交付和AI旧登陆入口遗漏了新增规则。
- 缺失检查：未验证历史地理归属、同国离岛邻接、场景后人力、失港生产与AI/玩家共享规则；新国家元数据曾依赖易错的tuple数字索引。
- 防错规则：几何身份独立于控制权；跨海必须海路；场景覆盖后重算经济人口；军种能力共用静态定义和可用性函数；海军交付需港口；AI与玩家复用登陆引擎；元数据用具名解构并验证初始化。记录浏览器连接失败，数据预览不充当界面截图。

- 根因：战线、候选攻击箭头、命令连线、港口悬停海路和战斗动画叠加；SVG 的外层 CSS 放大让 non-scaling-stroke 边界仍变粗。单线程静态服务器接受空闲预连接后阻塞其他资源，导致首屏脚本未载入；错误监听放在 main 末尾只捕获次生 undefined。

- 防错规则：地图以端点为命令标记，所有长期线层均需检查；CSS 外层缩放要补偿线宽并实际截图；启动诊断先于所有业务脚本，验证真实新标签；服务器回归同时覆盖空闲预连接、并发资源字节完整性；测试先 node --check 再执行。确认与取消固定可见、调整兵力即时反映真实出击数量；UI推荐枚举真实出发地的向外邻接，不能假设图双向。

- 防错规则：手动单步与自动下令明确分离，自动只攻击已宣战敌国、保留留守并使用真实部队；计时器串行安排下一天、暂停作废旧回调、继续记住档位；日期/月末统一一次保存刷新，批处理内部操作延后刷新。计时器回归必须覆盖默认后勤、事件恢复、月末和停战；夹具只改目标省份且保持真实全局契约。右栏一次只给选定对象的核心操作，选择器聚焦暂停避免刷新打断。浏览器工具故障时记录原始错误，不把 VM 或 HTTP 检查称为实机验收。
